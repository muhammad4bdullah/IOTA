The Igames catalog

Igames lists free games. The public catalog does not require a player account, and Igames does not process payments. Game installers are hosted by an external file host, not by Igames. Igames does not store or scan installer files.

Information this site processes

  • Saved games: If you save a game, its identifier is stored in your browser's local storage. It remains there until you remove it or clear your browser data.
  • Download requests: When you request a game download, Igames records the game and request time to count requests. A request does not show whether a download completed. These records are deleted when the related game record is deleted.
  • Administrator sign-in: The publisher dashboard uses a secure, HttpOnly session cookie for administrator access. It expires after 12 hours. Failed sign-in attempts are rate-limited using a keyed hash of the connecting IP address; the raw address is not stored in that rate-limit table. Old attempt records are cleaned up during later failed sign-ins.
  • Service requests: Cloudflare delivers and hosts the site and database. Cloudflare may process technical information such as connection and request data to provide and secure its services, subject to its own terms and privacy disclosures.

Hosting, storage, and security

The website and catalog database use Cloudflare Pages, Pages Functions, and D1. When you request a download, Igames redirects your browser to the file host configured for that game. The file host then handles your connection and any download under its own terms and privacy policy. Review Cloudflare's and the relevant file host's current privacy disclosures for details about their processing, locations, and retention.
